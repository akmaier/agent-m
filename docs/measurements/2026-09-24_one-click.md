## Two tests that were wrong at first

- `/explain/` did not match the first error message ("has no explanation", "EXPLAINS"): message
  changed to name the field.
- The storage checks matched the **word** `localStorage` in the newcomer explanation ("saved in this
  browser only (its `localStorage`)"). Sharpened to match **access** (`localStorage.` / `[` and the
  `globalThis.` form); the first sharpening then missed the store module's own
  `globalThis.localStorage;` — caught because the test expects exactly that module. Counter-proofs
  for word, access and the `globalThis` form are in both tests.
