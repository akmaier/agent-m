# "Phase" for the process model, instead of "stage"

**PO decision, 2026-09-24:** *job* for a run, *phase* for the parts of a process model — the book's own
word (ch. 6, vocabulary: activity, artifact, phase, role).

`THE MODEL DETERMINES THE STAGES AND THE GATES` is **withdrawn**, not reworded: its name contains the
word being retired, and a name is the ID. Its successor `THE MODEL DETERMINES THE PHASES AND THE GATES`
has the same rule with "phase". Three other rules in §5 change one word each in their text; their names
stay. Impact: UC-002 (now names the successor) and UC-031 (drafted with it).
