# 10. Review on GitHub Pages: several files are accepted from their list

**The change.** In `SEVERAL FILES ARE ACCEPTED IN ONE CLICK`, "A reviewer who has been shown several reviewed files —
opened one by one, or together on one review page — may accept all of them" becomes "A reviewer may accept several
reviewed files with one click — ticked on their list, or shown together on one review page —", and each record names "the
text the page read of that file". The check follows: one record per file ticked or shown, none for a file not ticked. The
counter-proofs stay. The rest of the section is as it stands.

**Why.** akmaier, 2026-11-01: "No, this is bull. I don't want this. I will not cross read all module changes." Sprint 141's
ITM-1349 had made the list offer a tick only for a file the tab had shown, as the old text asked ("none for a file that was
not shown"). The reviewer decides what to read; the record still names the exact text accepted (`AN APPROVAL NAMES THE EXACT
TEXT`), and a file changed since the page read it is still left out and named.

**Alternatives.**
- Keep the rule and accept from Review all only: every file not accepted on one page. That still makes the reviewer page
  through every module's text before one click.
