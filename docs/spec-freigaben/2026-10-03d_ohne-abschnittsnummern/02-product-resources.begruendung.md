# 15. Product resources: no section number

**The change.** In the rule of `A RESOURCE IS USED, A PARTICIPANT DEVELOPS`, the reference "(§5)" is removed; every other
requirement of the section is carried over byte for byte.

**Why.** "§5" names a position in the SPEC, not an identifier (`A REFERENCE NAMES THE IDENTIFIER, NOT THE POSITION`); the
rule reads the same without it.

**Impact list.** `A RESOURCE IS USED, A PARTICIPANT DEVELOPS` is named by
`docs/use-cases/UC-040-declare-the-products-resources.md` and `docs/architecture/MOD-source-library.md`; neither names the
removed reference. The rule's meaning is unchanged.
