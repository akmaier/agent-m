# 8. Versioning: provenance in the commit

**The change.** `AN ARTIFACT RECORDS THE VERSION THAT PRODUCED IT`: the Agent M version, the participant and the model that produced a generated artifact are named
in the commit that writes it, no longer in the artifact's text. The rest of the section is carried over byte for byte.

**Why.** The old rule put "the date of its generation" into the document and contradicted `A DOCUMENT HOLDS NO HISTORY`;
the stamps at the foot of every architecture file came from it. The commit is the version history.
