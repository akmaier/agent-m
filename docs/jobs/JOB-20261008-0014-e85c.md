### Verification needed

`endpoint-test` request, that the Bridge makes exactly one local endpoint request and returns `testEndpoint`'s result or
diagnosis, and that no browser request reaches that local endpoint. Existing direct-endpoint and bridged-zero-direct
tests remain required regression evidence. ITM-261 guards UC-003, loopback, token, pairing and credential-URL rules;
ITM-262 guards UC-003, unsupported-endpoint diagnosis, browser configuration and repository-secret rules; ITM-263 guards
UC-003, credential-URL and remote-failure rules; ITM-268 guards UC-003 and repository-secret rules. The architecture-file
format check passes for this draft.

### Alternatives rejected

- A browser call through MOD-endpoint-calls for the local configuration conflicts with UC-003 alternative 2a and its
  no-cross-origin setup.
- An installed CLI through `askAgent` or `bridgeAgentDriver` is a different participant contract and cannot perform the
  configured endpoint test.
- A generic Bridge HTTP proxy or a new runtime driver broadens the operation beyond the one explicit local test.
- A duplicate OpenAI-compatible or Anthropic request implementation duplicates `testEndpoint`.
