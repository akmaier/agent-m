# SRC-de-tdddg TDDDG — Telekommunikation-Digitale-Dienste-Datenschutz-Gesetz

§ 25 governs storing information on, and reading it from, a user's device. D.AI.Y keeps the skill profile and the inventory on the device (FR-10, FR-11), so this is the rule on when that needs consent. The file's own abbreviation is still TTDSG, the law's earlier name.
