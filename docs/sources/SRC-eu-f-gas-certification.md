# SRC-eu-f-gas-certification F-gas certification — Implementing Regulation (EU) 2024/2215

The minimum requirements for the certificates of persons and companies who work on refrigeration, air-conditioning and heat-pump equipment. Read together with SRC-eu-f-gas-regulation for the refrigerant-circuit exclusion.
