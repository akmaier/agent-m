# SRC-eu-f-gas-regulation F-gas Regulation — Regulation (EU) 2024/573

The regulation on fluorinated greenhouse gases. It backs the scope exclusion for refrigerant circuits (heat pumps, air conditioning): leak checks and installation need certified persons (Art. 5, Art. 10).
