# Products of this instance

The product repositories this Agent M instance manages (SPEC §10 `THE INSTANCE LISTS ITS PRODUCTS IN
A FILE`). The dashboard offers each of them in its product selector; the instance's own repository
is always offered first and is not listed here.

One product per line, exactly in this form — anything else is ignored:

```
- `owner/name` — optional short description
```

Adding a product is a commit to this file; the dashboard's **Add product** button opens it in
GitHub's editor. A product repository needs no Pages site: its artifacts live below its own `docs/`
and are reviewed here (`A MANAGED PRODUCT NEEDS NO PAGES SITE`).
