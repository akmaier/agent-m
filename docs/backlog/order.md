# The order of the backlog

**REGISTER**

The backlog's items in their order (`docs/backlog/`): first the items that implement modules, a module's after those of
the modules whose interfaces it uses, then the tests of the system.

MOD-source-register has three gaps, found while ITM-217 was built: a version's files stand under a heading that changes
with each version, which no schema can name; nothing checks the class a licence declares; and the module's file names a
source of kind `repository`, which is none of the seven kinds. developer-opus-a drafted a change to the module's file for
them on its branch `draft/MOD-source-register-files-licence-content` (`53da125`). They are not taken further now; each
goes to the item that first needs it.
