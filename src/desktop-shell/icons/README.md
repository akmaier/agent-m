# The Bridge's icons

**REGISTER**

The app's icon for each platform (`macos.png`, `windows.png`, `linux.png`, the names `appDescription` gives) and the icon of the
menu bar and the tray (`tray.png`, 16×16, and `tray@2x.png`, 32×32, which Electron takes on a screen of twice the density). Each
is the sign of the Pattern Recognition Lab, `src/brand/prl-sign.png`, scaled and set on a white square (the tray's on a transparent
one). The logo is not covered by Agent M's MIT licence; see `src/brand/README.md`.
