# The shipped catalogue

**REGISTER**

The book's process models and practices that Agent M ships (`AGENT M CARRIES THE BOOK'S CATALOGUE`), one file each, in
the folders `models/` and `practices/` of MOD-model-catalogue. The module reads this list when it is loaded, and then each
file it names: a browser cannot list a folder. A model or a practice is added by its file and its line here, and by no
change to the module's code (`THE CATALOGUE IS DATA`).

- `models/waterfall.md`
- `models/v-model.md`
- `models/reuse-oriented.md`
- `models/scrum.md`
- `models/kanban.md`
- `practices/devops.md`
- `practices/prototyping.md`
- `practices/incremental-delivery.md`
- `practices/scaling-layers.md`
