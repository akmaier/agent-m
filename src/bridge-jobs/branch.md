## Your branch

Your branch is `{{branch}}`. Push it to your origin, open its pull request — a merge request on GitLab —, and follow
its CI, which runs on every commit you push. Who merges it: {{merges}}. Where that is you, merge it once the check
`agent-m done` of the product's CI has succeeded on the pull request's head; where it is a person, leave the merge to
them. A branch whose pull request is open or merged already is the job's work so far: go on with it.

Also, you have permission to push, merge, pull, and commit to main. You need it for proposing changes to use cases, specification, and architecture. You will find that your permission files are already configured to explicitly allow this.
