# Products

In a local clone of Agent M, each product you check out is a clone of its own repository, in its own
folder here under `products/`. Git ignores these folders — everything in `products/` except this
file — so the number and names of your products are never visible in this repository, and a fork
can be synced with Agent M without conflict.

The dashboard keeps its list of products in your browser's storage, not in this repository.
(SPEC §10 `A LOCAL CLONE HOLDS ITS PRODUCTS IN ITS PRODUCTS FOLDER`, `NO PRODUCT IS NAMED IN THE
INSTANCE REPOSITORY`.)
